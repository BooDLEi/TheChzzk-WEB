치지직 팔로우 불러오기 (보안 1회성 연동)

치지직 통나무 파워 제도가 종료되어 더 이상 상시 로그인이 필요하지 않습니다. 사용자의 네이버 계정 보안을 철저히 보호하기 위해 로그인 세션 쿠키를 프로그램에 영구 보관하지 않습니다.

[치지직 팔로우 불러오기]를 실행하면 네이버 로그인 후 치지직의 팔로우 목록을 1회만 안전하게 불러와 즐겨찾기에 자동 등록하며, 작업 완료 즉시 로그인 쿠키와 인증 토큰은 메모리와 디스크에서 영구 삭제됩니다.

치지직 계정 팔로우 목록 가져오기
로그인 완료 즉시 팔로우 채널을 즐겨찾기로 등록하고 세션 쿠키는 자동 파기됩니다.
보안 모드 활성화
계정 정보가 파일에 저장되지 않으며, 즐겨찾기 탭에서 채널을 안전하게 관리합니다.
쿠키 문자열로 1회 불러오기 (고급 사용자용)
Cloudflare 1.1.1.1 보안 프록시 (IP 밴 방지)
동시에 다수의 고화질 라이브를 시청하거나 새로고침할 때 발생할 수 있는 IP 차단(IP 밴) 및 통신사 속도 제한(Throttling)을 방지하기 위해 프록시를 사용할 수 있습니다. Cloudflare WARP(1.1.1.1) 또는 사용자 정의 프록시(SOCKS5/HTTP)를 지원합니다.
보안 프록시 활성화
치지직 및 유튜브 스트리밍 연결을 지정된 프록시를 통해 경유합니다.
재생 진단 및 상황 로그 (상황로그파일)
멀티뷰 스트리밍 중 발생하는 버퍼링, 지연 추적(Catch-up), 프록시 연결 및 자동 복구 내역을 실시간 기록합니다. 끊김 문제가 발생했을 때 아래 로그를 복사하여 전달하시면 문제 원인을 정확히 파악할 수 있습니다.
