# 더치지직 (The Chzzk) Web Edition
더치지직 PC 프로그램 UI 그대로, 별도 프로그램 설치 없이 아이폰(Safari) 및 모든 컴퓨터 브라우저에서 사용하는 공식 웹 에디션입니다.

## 퍼블릭 배포 보안 구조
- 이 저장소에는 백엔드 소스코드, GitHub 토큰, 개인 쿠키, 즐겨찾기 JSON 파일이 일절 포함되지 않습니다.
- 모든 즐겨찾기, 유튜브 재생목록, 나중에 볼 영상, 시청 기록, 알고리즘 키워드는 접속한 사용자의 브라우저 내부(`localStorage`)에만 독립적으로 보관됩니다.
- 따라서 Public(공개) GitHub Pages로 배포하더라도 개인 데이터가 타인과 공유되거나 민감 정보가 노출될 위험이 전혀 없습니다.

## 주요 기능
- 프로그램과 100% 동일한 UI (탐색, 유튜브, 즐겨찾기, 플레이어, 클립, 녹화, 편집, 설정)
- 아이폰(iOS Safari) 반응형 지원 및 '홈 화면에 추가' PWA 지원
- 브라우저 실시간 방송 녹화 (완료 시 기기 다운로드 폴더로 즉시 저장)
- 파일 탐색기 영상 업로드 및 브라우저 내부 컷편집 / 내보내기 다운로드
